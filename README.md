# Jarvis (Android)
1. Push this folder to a GitHub repo (branch `main`).
2. Actions tab > "Build Jarvis APK" > download the `jarvis-debug-apk` artifact, install on your phone.
3. Open the app, do the 5 setup steps once (needs an OpenRouter API key (openrouter.ai/keys) and a free Picovoice access key).
4. After that just say: "Jarvis", then your command.
Use Copilot with `.github/copilot-instructions.md` to extend it (confirmations, overlay, screenshots, more actions).
